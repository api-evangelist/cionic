# CIONIC

> CIONIC Inc. builds "bionic clothing" for people with neurological conditions that
> affect walking. Its FDA-cleared Neural Sleeve combines inertial and surface-EMG
> sensing with functional electrical stimulation to analyse gait and assist
> dorsiflexion. Alongside the device, CIONIC runs a research platform — the Cionic
> Research Kit — with on-body hardware, iOS/Android collection apps, a web research
> portal, a hosted JupyterLab environment, and REST APIs for studies, protocols,
> collections, participants and accounts.

Generated by API Evangelist on 2026-08-09 from the CIONIC public surface. CIONIC does
not publish an llms.txt of its own; /llms.txt on cionic.com returns the marketing
homepage (a soft 404, confirmed against a control path).

## APIs

- [CIONIC Research Platform API](https://cionic.com/platform): Collections service.
  Path-versioned REST under `https://cionic.com/c/v{version}/{org}/` — studies,
  protocols and protocol versions, collections, collection files, streams, neighbors,
  participants, jobs, surveys, apps. Requires an `x-cionic-user` token.
- [CIONIC Accounts API](https://cionic.com/platform): Accounts service. Path-versioned
  REST under `https://cionic.com/a/v{version}/` — account lookup and creation,
  `/accounts/@me`, downloadable tokens, participants, timezone, per-organization role
  grants, chats, appointments. Fronted by OAuth 2.0 authorization code at
  `/oauth/authorize` and `/oauth/token`.

## Specs

CIONIC publishes no machine-readable API contract. There is no OpenAPI, AsyncAPI,
GraphQL SDL, Postman collection or JSON Schema on any CIONIC host. The nearest thing
to a contract is the first-party open-source client below.

## SDKs and tools

- [cionic-data](https://github.com/cionicwear/cionic-data): official Python client and
  analysis library, MIT licensed. Installed from source — not published to PyPI.
- Command-line scripts: `download.py` (sync and segment collections), `auth.py` (grant
  and revoke org roles), `upload_electrode_config.py` and `download_electrode_config.py`.
- Dockerised JupyterLab image with CIONIC's standard gait, metrics and signal notebooks.

## Authentication

- Token header `x-cionic-user` on every API request. Researchers download `token.json`
  from the profile menu at <https://cionic.com/a>.
- OAuth 2.0 authorization code at `https://cionic.com/oauth/authorize` and
  `https://cionic.com/oauth/token`; a bearer token is exchanged at
  `https://cionic.com/oauth/user` for the platform token. No scope reference published.
- Authorization is per-organization roles: `analyst`, `collector`, `admin`.
